# 💰 Finance AI - 100% GRATUITO para Casais

## 🎯 **OBJETIVO**: Economizar dinheiro para você e sua esposa!

### ✅ **SETUP GRATUITO COMPLETO (5 minutos)**

#### 1. **Configure o Supabase (GRÁTIS)**

1. Vá em [supabase.com](https://supabase.com)
2. Crie conta gratuita
3. **New Project** → Nome: "finance-ai"
4. **SQL Editor** → Cole o conteúdo de `supabase-schema.sql` → **RUN**
5. **Settings** → **API** → Copie URL e ANON KEY
6. Cole no `.env.local` (já está configurado! ✅)

#### 2. **Execute o Projeto**

```bash
npm run dev
```

**Acesse**: http://localhost:3000
